# Code

This directory contains code implementations of the algorithms in the book *Machine Learning Methods*. This is the first batch of code to be released, and more will be added gradually. The code implementations are closely integrated with the book's content, making it convenient for readers to further study the algorithms and conduct related experiments.

> **Disclaimer:** This code repository was completed by the author with the assistance of AI. The author devoted considerable effort to algorithm implementation design, standardization, and readability optimization.

## Contents

- [Supervised Learning](./Supervised_Learning/)
- [Unsupervised Learning](./Unsupervised_Learning/)
- [Deep Learning](./Deep_Learning/)

## Algorithms

### Supervised Learning

- Linear Regression
- Perceptron
- k-Nearest Neighbors (k-NN)
- Naive Bayes
- Decision Trees
- Logistic Regression
- Support Vector Machines (SVM)
- Boosting Methods (AdaBoost and GBDT)

### Unsupervised Learning

- Clustering Methods (k-Means)
- EM Algorithm
- Markov Chain Monte Carlo Methods (MCMC: Metropolis-Hastings Algorithm and Gibbs Sampling)

### Deep Learning

- Feedforward Neural Networks (FNN)
- Convolutional Neural Networks (CNN)
- Transformer
- Generative Adversarial Networks (GAN)
- Variational Autoencoders (VAE)
- Diffusion Models
- Flow Matching Models
