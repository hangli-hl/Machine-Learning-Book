# Codes 代码

This directory contains code implementations of the algorithms in the book *Machine Learning Methods*. This is the first batch of code to be released, and more will be added gradually. The code implementations are closely integrated with the book's content, making it convenient for readers to further study the algorithms and conduct related experiments.

本目录收录了《机器学习方法》一书中算法的代码实现。本次发布为第一批代码，后续将持续补充。代码实现与书中内容紧密配合，便于读者深入学习相关算法并开展实验。

## Contents 目录

- [Supervised Learning](./Supervised_Learning/) - 监督学习
- [Unsupervised Learning](./Unsupervised_Learning/) - 无监督学习
- [Deep Learning](./Deep_Learning/) - 深度学习

## Algorithms 算法

### Supervised Learning 监督学习

- Linear Regression - 线性回归
- Perceptron - 感知机
- k-Nearest Neighbors (k-NN) - k 近邻法
- Naive Bayes - 朴素贝叶斯法
- Decision Trees - 决策树
- Logistic Regression - 逻辑斯谛回归
- Support Vector Machines (SVM) - 支持向量机
- Boosting Methods (AdaBoost and GBDT) - 提升方法（AdaBoost 与 GBDT）
- Hidden Markov Models (HMM) - 隐马尔可夫模型
- Conditional Random Fields (CRF) - 条件随机场

### Unsupervised Learning 无监督学习

- Clustering Methods (k-Means) - 聚类方法（k 均值聚类）
- EM Algorithm - EM 算法
- Markov Chain Monte Carlo Methods (MCMC: Metropolis-Hastings Algorithm and Gibbs Sampling) - 马尔可夫链蒙特卡罗法（MCMC：Metropolis-Hastings 算法与吉布斯抽样）

### Deep Learning 深度学习

- Feedforward Neural Networks (FNN) - 前馈神经网络
- Convolutional Neural Networks (CNN) - 卷积神经网络
- Recurrent Neural Networks (RNN) - 循环神经网络
- Transformer - Transformer
- GPT and BERT - GPT 与 BERT
- Autoencoders (AE) - 自编码器
- Generative Adversarial Networks (GAN) - 生成对抗网络
- Variational Autoencoders (VAE) - 变分自编码器
- Diffusion Models - 扩散模型
- Flow Matching Models - 流匹配模型
