# Codes

This directory contains code implementations for the algorithms described in *Machine Learning Methods*. It is still under development. Some codes will be released shortly.

本目录包含《机器学习方法》中算法的代码实现。代码开发中，近期将公开一部分。

## Machine Learning Methods

### Supervised Learning

- Linear Regression
- Perceptron
- K-Nearest Neighbors
- Naive Bayes
- Decision Trees
- Logistic Regression Model
- Support Vector Machines
- Boosting Methods (AdaBoost and GBDT)
- Hidden Markov Models (HMM)
- Conditional Random Fields (CRF)

### Unsupervised Learning

- Clustering Methods (K-Means)
- Principal Component Analysis (PCA)
- EM Algorithm
- Latent Semantic Indexing (LSI)
- Probabilistic Latent Semantic Analysis (PLSI)
- Latent Dirichlet Allocation (LDA)

### Deep Learning

- Feedforward Neural Networks (FNN)
- Convolutional Neural Networks (CNN)
- Recurrent Neural Networks (RNN)
- Transformer
- GPT and BERT
- Autoencoders (AE)
- Generative Adversarial Networks (GAN)
- Variational Autoencoders (VAE)
- Diffusion Models
- Flow Matching Models

### Reinforcement Learning

- Markov Decision Processes
- Multi-Armed Bandits (MAB)
- Value-Based Methods (Q-Learning, SARSA)
- Deep Q-Networks (DQN)
- Policy-Based Methods (REINFORCE)
- Proximal Policy Optimization (PPO)
